# 明确的记忆模型连接与可读字号设计

## 目标

用户必须能够看懂并控制“后台整理记忆到底使用哪个模型”，同时所有可见文字在手机和桌面上都保持可读。

## 模型连接

设置只允许选择一种来源：

1. 自己填写 API：填写 OpenAI 兼容基础地址、访问密钥和模型名称；可从 `/models` 读取列表，也可手动填写。
2. 使用 SillyTavern 已保存的连接：选择连接配置，并可选填模型名称覆盖配置内的模型。
3. 跟随当前聊天模型：明确随酒馆当前模型变化，不能在插件里单独选模型。

三条路线互斥。调用失败后保留任务并进入现有重试流程，不得静默切换到另一条路线。旧版备用 API 配置自动迁移为“自己填写 API”，旧版连接配置自动迁移为“使用已保存的连接”。

## 字号与触控

- 插件正文和表单以 `1rem`（通常为 16px）为基准。
- 辅助文字的最小字号为 `0.875rem`（通常为 14px）。
- 状态数字使用正文尺寸，不再缩小为徽标式数字。
- 按钮、输入框和粗指针触控目标不低于 44px。
- 手机宽度下不通过缩小文字换空间；内容改为换行、纵向排列或局部滚动。

## 验收

- 三种来源切换时只显示对应字段。
- 已保存连接显示连接名和已知模型；用户始终可以手动覆盖模型名。
- 连接检查回显实际选中的模型标签。
- 360×640 视口无页面级横向溢出，所有可见文字计算字号不低于 14px，状态数字为 16px。
