# 幕间叙述者设计

## 目标

在 SillyTavern 输入区旁增加一个“幕间”入口。玩家可以暂停剧情，与刚才的同一个叙述者直接讨论剧情、询问连续性或调整下一段走向；讨论结束后，由叙述者立即生成下一层正文。整个过程不要求玩家选择卡片、期限或结构化选项。

## 核心体验

1. 玩家点击输入区旁的面具按钮，打开幕间窗口。
2. 幕间使用当前主模型、当前连接、当前角色/预设和当前剧情上下文；额外提示模型暂停正文，以叙述者身份直接交流。
3. 玩家和叙述者自然对话。关闭窗口只保存草稿，不触发正文。
4. 玩家点击“可以了，继续！”，插件把完整幕间对话包装成一条玩家输入，要求模型从暂停处直接继续剧情。
5. 主聊天只显示紧凑的“幕间讨论”标记；完整输入保存在该消息中，可点击重新查看，但不会作为剧情正文进入插件的摘要和事实来源。
6. 生成结果是新的 assistant 楼层。该楼层的全部 swipe 使用同一版幕间输入。
7. 如果结果不满意，玩家从该回复的消息操作中点击“回到幕间”，继续告诉叙述者哪里不对；再次生成时更新幕间输入，并创建同一 assistant 楼层的新 swipe。

## 数据与隔离

- 每个聊天在 `chatMetadata.layered_memory.backstage` 下保存幕间会话、工作草稿和不可变的生成版本。
- 每个版本保存当时的完整幕间消息、被否决的正文草稿和目标 swipe 的引用。
- 幕间玩家消息通过 `extra.layered_memory_backstage_marker` 标识，assistant 候选通过 `extra.layered_memory_backstage` 记录会话和版本；SillyTavern 的 `swipe_info.extra` 保留每个候选的来源。
- 幕间全文是当前生成的真实玩家输入，因此由酒馆按正常 token 预算处理；插件不静默截断或自动总结。
- 插件的剧情正文、近期原文、事实提取和时间证据把幕间玩家楼视为没有剧情正文。生成出的 assistant 正文仍照常进入逐楼摘要和事实提取。
- 会话跟随聊天元数据和分支复制；切换聊天、分支或 swipe 时不得串用其它会话的工作草稿。

## 生成生命周期

- 首次继续：把幕间全文放入输入框请求，走 SillyTavern 普通生成；`MESSAGE_SENT` 发生时补上紧凑显示和会话来源。
- 重写：修改原幕间玩家消息，建立新版本，把当前 assistant 置为下一 swipe 槽，再走 `Generate('swipe')`。
- 普通右滑生成：如果当前 assistant 来源于幕间，沿用其当前幕间版本。
- 取消、停止、网络错误或刷新不会删除工作草稿。只有成功保存 assistant 候选后，版本才标记为已生成。
- 玩家发送后续普通正文输入后，本次会话归档；历史标记仍可查看，但不能从旧楼层直接改写已经继续发展的故事。

## 幕间模型提示

幕间回复要求模型：

- 作为刚才的同一个叙述者说话，而不是独立顾问或剧情角色；
- 暂停剧情，不续写场景，不替玩家作决定；
- 可以坦率说明叙事意图、承认连续性问题、提出方案并接受玩家否定；
- 只输出给玩家看的自然对话，不输出 JSON、标签或内部说明。

回到剧情的玩家输入要求模型：

- 把幕间全文视为非正史的创作讨论；
- 较晚的修改和否定覆盖较早的提议；
- 未经玩家同意的提议不得擅自采用；
- 直接输出正文，不提及幕间、讨论、约定或玩家要求。

## UI 方向

视觉采用“现代编辑室 / 拉开幕布”的克制方向：与 SillyTavern 主题融合的暖色中性表面、少量铜色强调、衬线标题与清晰正文层级。窗口使用原生 `dialog` 进入顶层，桌面为可展开的居中编辑室，移动端为安全区内的全高底部面板。

- 入场使用 280–360ms 的透明度与轻微上移/缩放；退场更快。
- 动效只使用 `transform` 和 `opacity`，并支持 `prefers-reduced-motion`。
- 对话按说话者形成阅读节奏，不使用重复的卡片气泡。
- 所有图标按钮有可读标签，键盘焦点可见，触控目标不小于 44px。
- 发送区支持 Enter 发送、Shift+Enter 换行和中文输入法合成保护。
- 加载、失败、停止和重试都有明确状态；失败不删除玩家刚才的话。

## 验收

- 桌面和 390×844 移动视口均可打开、关闭、展开、输入、发送和继续。
- 幕间讨论完整出现在下一次真实 provider 请求中，实际玩家输入显示为紧凑标记。
- 正常生成和流式生成都能关联会话版本。
- 修改幕间后生成新 swipe，旧候选的正文、事实和来源不会进入新候选。
- 幕间玩家楼不进入剧情摘要、近期原文正文、事实和时间证据；assistant 正文正常进入。
- 刷新、停止生成、切换已有 swipe 和切换分支后状态保持正确。
- `npm test` 全部通过，并在真实 UI harness 检查动画、焦点、移动端安全区和长文本滚动。
