# V3.35 紧凑显式 Thinking 设计

## 目标

保留 V3.35 在正文前逐项显式思考的结构，使模型仍需公开确认输入、人设、关系、信息边界、文风、剧情推进、权限与格式；同时删除重复抄写、通用教程和同义复核，将目前约 3800–4200 字符的 `<Think>` 压缩到简单回合约 800–1200 中文字符、复杂回合约 1200–1800 中文字符。

## 原则

1. 不关闭任何当前已启用 Prompt，不改变 Prompt 顺序、角色、模型参数或抢话开关。
2. 后续每个 `## Step` 仍须在可见 `<Think>` 中留下具体结论，不得改成隐藏思考或只写“已检查”。
3. 强迫思考依靠本轮具体判断，不依靠重复问题、完整复述设定或凑字数。
4. 简单步骤通常写 1–3 行；存在多人、重大转折、设定冲突或权限歧义时可以展开，但整个 `<Think>` 不应超过复杂回合上限。
5. 已有 `⚪️世界自治与剧情生长` 的内容和位置不变；`辣椒油有趣剧情` 显式提出候选，`推进速度` 负责选择并校验来源、时机、强度与后果。

## 修改范围

- `💙小克开启思维链💙`：保留显式思考、自我定位和逐步执行，取消“不得合并、缩减”造成的无上限展开，改为“不得跳步、每步给结论”。
- `💖[必开]确认输入`：显式概括上轮反应、本轮输入和用户意图，但不原样复制完整用户消息。
- `💖角色信息`：仍检查时代、地点、经济情况、用户与角色至少四个相关特征；改用关键词，不重写完整档案。
- `💙克推荐 小克轻自由意志@feybe`：九个检查维度全部保留，每项以本轮结论和对应行动作答。
- `💖关系思考`、`💖[二选一]文风确认`、`💖避坑指南`、`💖防全知`、`💖人设自检纠错`：保留各自显式检查，只报告本轮结论和具体风险，不输出通用写作教程。
- `💖辣椒油有趣剧情`、`💖推进速度`：保留剧情候选与最终选择的双阶段结构，避免把“主动推进”简化成每轮强制事故。
- `💖部分要求确认`、`💖格式确认`：保留权限和附加格式确认，改为紧凑字段。
- `🔵小克卡cot@人间月下`：继续强制可见 `<Think>`，要求按顺序显示所有步骤及答案，并施加总长度与禁止填充规则。
